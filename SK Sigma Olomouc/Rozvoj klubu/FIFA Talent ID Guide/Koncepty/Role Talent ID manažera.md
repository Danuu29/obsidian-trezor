# Role Talent ID manažera

(Jan Verbeek, KNVB; Tobias Süveges, Werder Bremen)

- Identifikuje a doporučuje mladé hráče řediteli akademie – ty, kteří nejlépe zapadnou do klubu.
- Hledá hráče, kteří se snadno adaptují na tréninkové prostředí a mají potenciál projít pathway až do A-týmu.
- Klíčové: **silné propojení s ředitelem akademie** → hluboké pochopení filozofie a vize, aby hledal správný typ hráčů.
- Po definici kritérií a požadovaného skill setu vede tým při hledání.
- Hodnotí vše: techniku, fyzickou kapacitu, růstový potenciál, osobnost, kulturní a rodinné zázemí.
