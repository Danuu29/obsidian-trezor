# Společný fotbalový jazyk

**FIFA Football Language** – jednotný jazyk a sladěný datový set výkonu, vytvořený FIFA s technickými experty, analytiky a datovými vědci.

- Data jsou dnes široce dostupná → nejde o to, kdo je má, ale **kdo je umí použít**.
- Wengerova vize: *Enhanced Football Intelligence (EFI)* = kombinace expertního technického pozorování a datové analytiky.
- Základ: jednotlivý hráč a jeho akce s míčem **i bez míče** (např. „Offering to receive“, „Defensive pressure“), včetně dopadu akce na tvar soupeře.
- Klíč: rovnováha mezi datovými insighty a technickou interpretací, vždy s fotbalovým kontextem.

**Pro talent ID:** objektivní data pro rozhodování + společný jazyk zajistí, že skauti a recruiteři jsou sladění.
