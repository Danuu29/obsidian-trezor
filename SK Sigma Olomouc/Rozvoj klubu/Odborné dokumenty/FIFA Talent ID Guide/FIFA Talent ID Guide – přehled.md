# FIFA Talent ID Guide – přehled

Technický průvodce FIFA (High Performance Programmes, Talent Development Scheme) pro budování spolehlivého systému identifikace talentů – pro kluby i svazy bez ohledu na velikost, rozpočet či geografii.

**Hlavní myšlenka:** identifikace talentu je základ celého systému rozvoje hráčů. Průvodce ji strukturuje do pěti logických kroků → [[Model dimenzí Talent ID]].

> Kontext: FIFA Ecosystem Analysis (2021) – jen 51 % svazů mimo top 50 mělo strategii talent ID a jen 35 % svazů na 51.–100. místě mělo systematický přístup.

## Dimenze

1. [[D1 Filozofie]] – kultura a hodnoty, co je potřeba k vítězství, herní a trenérská filozofie
2. [[D2 Profily]] – hráčské profily, profily kádru a depth charty, gap analýza
3. [[D3 Identifikace]] – systémy a procesy, skautingové prostředí, pozorování hráčů, data a analytika
4. [[D4 Výběr]] – long list, short list, rozhodovací proces, vyjednávání a výběr
5. [[D5 Konstanty]] – plan-do-review, vzdělávání v talent ID
