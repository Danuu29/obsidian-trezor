# Aplikace – Match tracker

„Klikací panel“ pro záznam statistik utkání v reálném čase (počítač/tablet/mobil). Zdroj: [[SK Sigma Olomouc/Aplikace/Zápas app - statistika/Aplikace zápas 🏟️|Aplikace zápas 🏟️]].

## Funkce

1. **Záznam** – nové utkání (datum, týmy + loga z databáze, typ utkání, volba panelu), časomíra s poločasy, tlačítka metrik pro domácí i hosty se záznamem minuty, editace a poznámky.
2. **Live report** – sdílený odkaz, metriky domácí vs. hosté, po poločasech.
3. **Celkový report** – 5minutové úseky, situace + komentáře, číselný souhrn.

## Rozpracované

- Práva po skupinách (uživatel vidí jen data své skupiny), přístup pro U17.
- Export vybraných dat (CSV/Excel) → nahrávání do [[Yarmill]].
- Držení míče (automatismus?), barvy metrik, přiblížit finální report vzoru.

## Inspirace z Barça kurzu

Code windows profesionálních týmů (Španělsko MS 2018, FFA), tlačítka **Review/Error**, statistické alarmy, live protokol analytik → asistent → trenér, poločasový balíček a live dashboard s max. ~9 metrikami → [[Live analýza a poločas]], [[Tagging a code window]], [[Mediacoach]]. Konkrétní návrhy → [[Barça kurz – návrhy pro Sigmu]].
