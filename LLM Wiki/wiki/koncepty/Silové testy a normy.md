# Silové testy a normy

Jak Sigma testuje sílu a skokové schopnosti ([[VALD]]), v jakém rytmu a jaké normy používá. Zdroje: [[SK Sigma Olomouc/Analytická témata/Předsezóní testování|Předsezóní testování]], [[SK Sigma Olomouc/Analytická témata/Preventivní testování VALD|Preventivní testování VALD]].

## Dva režimy testování

**Předsezónní** (začátek letní a zimní přípravy): profil hráče vs. průměr a vs. minulé testování → plán kompenzace a rozvoje slabin, skupinový rozvoj. Baterie: VALD dynamický + statický, [[InBody]], reakční test (tabular, norma do 55 s), schodový laktátový test (10/12/14/16 km/h; průměr laktátu 2,2 / 3,8 / 7,5 / 10).

**Preventivní v mikrocyklu (A-tým):**

| Test | Den | Účel | Hranice |
|---|---|---|---|
| Addukce/abdukce 45° | MD+3 | síla vnitřních/vnějších svalů před TJ se změnami směru | asymetrie < 15 %, pokles < 10 % |
| Nordboard Nordics (0 / 3 / 6 kg) | MD-3 | zadní řetězec před sprintovou TJ + progresivní silový stimul | asymetrie < 15 %, pokles < 10 % |
| Drop jump (RSI, výška) | MD-1/MD-2 | únava před utkáním | pokles < 15 % |

Při překročení → společně s fyzio snížit zátěž v další TJ. Zranění: navíc ISO PRONE.

**Důležitá metodická poznámka:** pokles se má počítat **vůči průměru posledních ~4–6 týdnů**, ne vůči poslednímu testu (předchozí test mohl být výkyv). Úkol: u DJ odstranit normu a do trendu dát vývoj diference.

## Souhrn norem (Předsezóní testování)

| Test | Min. síla | Změna vs. minule | Asymetrie |
|---|---|---|---|
| Nordic | 400 N | ≤ 10 % | ≤ 20 % |
| ISO 60 | 300 N | ≤ 10 % | ≤ 20 % |
| ISO PRONE | 280 N | ≤ 10 % | ≤ 15 % |
| Hip flexion | 200 N | ≤ 10 % | ≤ 15 % |
| Knee extension | 300 N | ≤ 8 % | ≤ 10 % |
| Knee flexion | 200 N | ≤ 8 % | ≤ 10 % |
| Ankle plantar flexion | 100 N | ≤ 10 % | ≤ 15 % |
| Hip AB/AD | 200 N | ≤ 10 % | rozdíl AB vs. AD ≤ 10 % |

Skoky: CMJ ≥ 35 cm, CMJA ≥ 40 cm, CMJ SL ≥ 25 cm (asymetrie ≤ 20 %), Hop test průměr ≥ 25 cm. Poměr flexe/extenze kolena: varování při flexi < 2/3 extenze.

> [!warning] Rozpor
> Zdroj obsahuje pro stejné testy různé hodnoty (Nordic 300 vs. 400 N, ISO PRONE 250 vs. 280 N, asymetrie Nordic 15 vs. 20 %, poměr AB/AD 0,8–1,0 vs. rozdíl ≤ 10 %, flexe ≥ 2/3 vs. ≥ 60 % extenze). Detail v [[Rozpory a nesrovnalosti]].

## Reporting

- Týmový přehled: jen grafika norma/mimo normu, % hráčů plnících normu, proklik do detailu hráče; hraniční hodnoty jinou barvou.
- Chybí v reportu: HOP test vizuál, CMJA (značení), Knee flexion, Hip flexion, Meloq.
- Pokud hráč v preventivním testu překoná výsledek z performance testu – přepsat automaticky? (otevřené)
