# Taktická komunikace

**Tactical communication (TC)** – sdílený slovník krátkých pokynů, které dávají prvkům hry taktický význam. Hráč pak zvládne víc informací sám; zprávy jsou detailnější, ale **kratší a méně časté** (P1 M4 [[Zdroj – Barça Match Analysis]]). Odpovídá potřebě jednotného názvosloví v [[Sigma Way]] a [[Společný fotbalový jazyk]] (FIFA).

## Bez míče

| Termín | Význam |
|---|---|
| Prepare | míč za záda – připrav se běžet |
| Join | zkrať vzdálenost ke spoluhráči |
| Weak side | uprav shifting na odvrácené straně |
| High / Medium / Low | výška 1. presinkové linie |
| Momentum | moment pro presink při výhodě |
| Orient | nuť soupeře hrát tam, kde nám to vyhovuje |
| References | znej přiděleného hráče („assessing is not marking“) |
| Adjust | rozpoznej dezorganizaci a vyvaž |
| 1 vs 1 | kdy jít do souboje |
| Jump | vystup z linie při převzetí s časem a vyrovnej linii |
| Wait for it | trpělivost při inferioritě, zůstat v liniích |
| Perimeters | nuť soupeře do větších perimetrů (čas na reorganizaci) |
| Overtake | linie ustupuje, zmenšit prostor za zády |
| Slide | zůstaň s přiděleným do konce akce |
| Trajectories | útočné trajektorie na nepřiděleného, zpomalit progresi |
| Intermediate | zmenši prostory za presinkovými liniemi |
| Gaps | zavři penetration gaps |
| Change | výměna soupeře (ověř, že ho má spoluhráč) |

## S míčem

| Termín | Význam |
|---|---|
| Heights / Axes | obsaď různé výšky / osy (umožni diagonály) |
| Subject / Mobilize | drž pozici (drží i soupeř) / pohni se, ať se pohne soupeř |
| Facilitate | possessor potřebuje prostor – nechoď k němu |
| Profiles | orientace těla pro další akci |
| Patience | kombinuj bez okamžité progrese |
| Amplitude | šířka – maximální vs. optimální |
| Separate / Distances | nabízej vzdálenější linie; relační vzdálenosti |
| Third man | koncept 3. hráče |
| Engage assigned man | possessor fixuje a staví příjem volného hráče |
| Compensate | pozice pro případ ztráty |
| Intermediate / Gaps | obsazuj prostory za presinkovými liniemi / napadej mezery |
| Move out of lane | přetížený prostor – postup jinudy |
| Recognize | poznej svůj kontext a roli |
| Accelerate | zrychli pro využití převahy |

## Použití (návrh)

Počeštit a sjednotit pro akademii; stejné termíny v klipech, prezentacích, na tabuli, v koučinku i jako číselník tagů v [[Yarmill]]. Sledovat konzistenci názvosloví v [[Analýza trenérské komunikace]].
